# 뉴스저울 콘텐츠 바이블

> 이 문서는 뉴스저울의 공식 콘텐츠 설계 기준입니다. 새로운 콘텐츠 아이디어가 나오면 구현보다 먼저 이 문서에 기록합니다. 최종 수정: 2026-07-10.

## 0. 핵심 문장

**뉴스저울은 뉴스를 보여주는 사이트가 아니라, 사람들이 클릭하고 싶은 질문을 보여주는 서비스다.**

콘텐츠 관련 모든 결정은 이 한 문장으로 먼저 거른다. "이게 뉴스로서 맞는가"가 아니라 "이게 질문으로서 매력적인가"를 묻는다.

## 1. Hero / 메인 피처카드 선별 기준

### 4문항 CTR 테스트 (2026-07-10 확정)
아래 중 **하나라도 아니오면 Hero·메인 피처카드에서 제외**한다(그리드 하위 카드에서는 소비돼도 됨):
1. 내가 이걸 클릭할까?
2. 가족이나 친구가 궁금해할까?
3. Threads에서 멈춰서 읽을까?
4. 유튜브 썸네일이었다면 눌렀을까?

### 절대 Hero/메인 피처카드에 올리지 않는 것
- 지자체/기관 행사, 보도자료성 콘텐츠
- 단순 행정 공지, 지역 정책 홍보
- 예: "경기도 이주민 포털 공식 개통", "취약계층 반려동물 의료비 지원"

### Hero에 올라와야 하는 것 — "메가 토픽"
사람들이 이미 알고 있고 계속 궁금해하는 화두. 예시(2026-07-10 사용자 제시):
GPT-6, AI, 트럼프, 이재명, 윤석열, 삼성전자, 엔비디아, 테슬라, 비트코인, 애플, 아이폰, 포르쉐, 현대차, 금리, 미국, 중국

**현재 구현 상태**: `lib/topics.ts`의 `pickHeroTopic()`이 위 키워드 화이트리스트로 1차 필터링 중(임시 조치, 승인 없이 이미 반영됨 — 코드 자체는 무해한 필터라 [2]항목 아님). 진짜 목표는 "행정 콘텐츠 배제 + 메가토픽 우선"을 자동으로 판별하는 것인데, 지금은 화이트리스트만 있고 배제 로직은 아직 반영 전(승인 대기 — §5 참고).

## 2. 질문형 제목 원칙

카드 제목은 기사 제목이 아니라 **사람이 머릿속으로 실제로 할 법한 질문**이다.

| 기사 제목(❌) | 질문형 제목(✅) |
|---|---|
| 취약계층 반려동물 의료비 지원 | 강아지 병원비, 앞으로 덜 내게 될까? |
| 포르쉐 신형 공개 | 포르쉐 신형, 지금 사면 호구일까? |
| 삼성전자 반도체 투자 확대 | 삼성 반도체, 진짜 다시 살아나는 걸까? |
| (예시 추가) | GPT-6, 정말 그렇게 대단해? / 비트코인, 지금 들어가도 될까? / 현대차는 왜 요즘 잘 나갈까? / 트럼프 관세, 결국 누가 이득일까? / 엔비디아는 아직도 더 갈까? / 금리는 언제 내려갈까? |

원래 팩트(예: "취약계층 반려동물 의료비 지원")는 낚시성으로 흐르지 않도록 30초 이해/본문에 그대로 살린다 — 제목만 질문형, 본문은 정직하게.

## 3. 본문 밀도 — "검색보다 만족스러운 답"

목표 문장: **"검색해서 여러 블로그를 돌아다니는 대신, 뉴스저울 하나만 읽어도 궁금증이 해결되는 경험."**

카테고리별 전문 매체 페르소나로 본문을 쓴다:
- 자동차 → 자동차 전문 블로그 톤
- AI/테크 → 전문 테크미디어 톤
- 경제 → 경제 칼럼 톤

구체적 수치·비교 대상·전망까지 포함해야 하며, 추상적 감상 문장은 금지한다. 읽고 나면 "더 찾아볼 필요 없다"는 만족감이 기준.

## 4. 절대 부활시키지 않는 구브랜드 문구 (2026-07 브랜드 Audit에서 확정)

- "당신이 놓쳤을 수 있는 뉴스"
- "침묵지수"
- "보수/진보", "보수 vs 진보"
- "언론사 편향", "편향 스펙트럼"
- "당신이 못 본 절반"

관련 레거시 코드(`components/NewsCard.tsx`, `TrackedSilenceSection.tsx`, `SilenceTop10.tsx`, `lib/relatedSections.ts`)는 전부 `@deprecated` 마킹 후 유지 중 — 삭제는 디지털 편집국 구축 이후 별도 승인.

## 5. 현재 한계 — 실데이터 현황 (2026-07-09 기준, 다음 세션에서 갱신 필요)

- 실제 Supabase에 있는 활성 토픽은 **32개뿐**이고, 전부 한국 국내 뉴스(정치/사회 사건 위주)다.
- 위 예시로 든 GPT-6/포르쉐/삼성전자/비트코인 같은 글로벌 메가토픽은 **지금 하나도 실존하지 않는다** — 가장 가까운 게 "삼성전자 반도체 실적 전망" 정도.
- 콘텐츠 소싱이 구글뉴스 RSS(한국 언론 20개사)뿐이라, 이 상태로는 이 바이블이 목표로 하는 콘텐츠를 만들 재료 자체가 부족하다. **파이프라인 정상화 + 소싱 확장 논의가 콘텐츠 품질 작업보다 먼저 필요** (자세한 진단은 [[뉴스저울 AI 편집국 바이블]] 참고).

## 6. 승인 필요 항목 (구현 금지, 보고 후 대기)

- 콘텐츠 생성 방식 변경, 질문 생성 로직 변경, AI 프롬프트 변경 — 전부 §7 미승인 목록에 해당. 이 바이블에 기록만 하고 구현하지 않는다.
