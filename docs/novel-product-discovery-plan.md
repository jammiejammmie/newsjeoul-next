# 신박한 발견 — 공통 편집 기획 v1.0

2026-10-26 사용자 지시: 신박한 상품은 영상 흥미를 만들 수 있으므로 뉴스저울 웹·테크쉽Get에 해당 카테고리를 두는 방향. 현재는 기획 확정/자료 조사 단계이며 실제 메뉴·블로그 카테고리·클립을 생성했다고 보고하지 않는다.

- 공통 코너 가칭: 신박한 발견. 일상 불편을 의외의 방식으로 해결하는 실제 제품을 다룬다.
- 클립: 작동 장면 → 해결하는 불편 → 작동 조건/제약 → 관련 상세 글·정확한 제품 태그. 실제 재사용 허가를 확인한 영상만 이용한다.
- 블로그·웹: 같은 원고 복제보다 각 채널 독자의 질문에 맞게 모델·한국 사용 조건·설치/호환·총비용·대안·안 사도 되는 경우를 완결한다.
- 분류 후보: 책상/디지털, 주방/집안일, 이동/휴대. 수량을 채우기 위해 빈 카테고리를 늘리지 않는다.
- 제품 선정: 시각적으로 보이는 기능, 구체적 불편 해결, 실제 제품/모델 검증, 한국 사용 가능성, 정확한 국내 판매/정식 제휴 링크, 영상 권한. 수수료율만으로 선정하지 않는다.
- 영상 속 모델과 판매 모델을 일치시킨다. 다르면 국내 대안이라고 명시하며 원래 제품의 기능을 대안에 옮기지 않는다. 콘셉트 영상/렌더는 양산품과 구분한다. 직접 체험하지 않은 후기는 만들지 않는다.
- 현재 테크쉽Get 쇼핑 커넥트 접속과 링크 발급 가능. 첫 확보 링크: 벨킨 AVC009 https://naver.me/FVF5vHqI . 아직 신규 원고·클립 게시나 카테고리 생성 없음. 네이버 채널용 링크 사용 정책과 광고 고지를 지키며, 웹 외부 채널 허용은 확인 후 적용한다.
- 조회→상품 클릭→유효 구매→확정 수익을 분리한다. 신박함이 CTR을 높인다는 가설은 실제 도달·클릭으로 시험한다. 노출·판매·수익 보장 없음.
- 비용: 새 유료 수집/AI API·구독·광고 결제 없음. 기존 웹 반복 운영과 SNS/소라 중단 상태는 유지한다.
