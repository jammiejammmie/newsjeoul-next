# 뉴스저울 2.0 User Journey v0.1

> 개발 문서가 아니다. 경험 설계 문서다.
> 기준 문서: [`docs/newsjeoul-2.0-product-bible.md`](./newsjeoul-2.0-product-bible.md)(철학) — 이 문서는 그 철학이 실제 사용자의 30초, 3분, 하루, 한 달 안에서 어떻게 체감되는지를 구체화한다.
> 셋의 관계: **Product Bible = 철학, Implementation Bible = 구현, User Journey = 경험.** 이 셋이 뉴스저울의 헌법이다.

# Part A. 시간축 마스터 저니

진입 경로(Part B)와 무관하게, 한 번 머물기 시작한 사용자가 공통으로 지나가는 심리·행동 궤적. 매 구간마다 **심리상태 / 무엇을 보는가 / 왜 클릭하는가 / 왜 머무는가 / 이 시점 KPI / 느껴야 하는 감정 / 다음 행동**을 정의한다.

## 진입 순간 (0~3초)
- **심리상태**: 판단 보류 상태. "이게 뭐 하는 곳이지?" — 인내심이 가장 낮은 구간.
- **무엇을 보는가**: 진입 경로별로 다름(Part B). 공통적으로 3초 안에 "이건 기사 목록이 아니다"라는 신호(3축 배지, 관계 카드 미리보기, 슬로건)가 보여야 한다.
- **왜 클릭하는가**: 이 구간은 클릭보다 "머무를지 결정"이 먼저다.
- **왜 머무는가**: 첫 화면이 "지금 뭔가 일어나고 있다"는 인상을 줄 때.
- **KPI**: 3초 바운스율.
- **느껴야 하는 감정**: 가벼운 긴장 섞인 호기심 — "어, 이거 뭐지?"
- **다음 행동**: 스크롤 또는 첫 스캔.

## 30초
- **심리상태**: 첫 화면 스캐닝 완료. 계속 머물지를 이 시점에 결정.
- **무엇을 보는가**: "지금" 섹션(상태 요약) 완독, 관계 카드 1~2개의 explanation을 스치듯 확인.
- **왜 클릭하는가**: explanation 한 문장이 "어? 왜 이게 연결되지?"라는 반응을 일으켰을 때 — 이게 실질적인 첫 딥 클릭.
- **왜 머무는가**: 첫 화면이 완결되지 않고 다음 궁금증을 남겼을 때(Product Bible 1장 "완결된 답은 이탈, 열린 답은 탐험").
- **KPI**: 30초 시점 스크롤 depth, 첫 관계 클릭률.
- **느껴야 하는 감정**: "생각보다 재밌는데?" — 약한 몰입의 시작.
- **다음 행동**: 관계 카드 클릭(다른 대상으로 이동) 또는 "역사" 섹션으로 스크롤.

## 3분
- **심리상태**: 이미 최소 1회 이상 다른 대상으로 이동한 상태 — 탐험 모드 진입 여부가 여기서 갈린다.
- **무엇을 보는가**: 두 번째·세 번째 대상 페이지. 처음과 다른 종류의 정보(예: Topic에서 Entity로 넘어감).
- **왜 클릭하는가**: 비교심리(경쟁 대상 노출), 반박심리(다른 헤드라인/해석).
- **왜 머무는가**: 매번 같은 골격(지금/연결/역사)이라 다음에 뭐가 나올지 예측 가능해 피로하지 않다.
- **KPI**: 3분 시점 누적 페이지뷰(세션당 탐험 깊이의 조기 신호), 이탈률.
- **느껴야 하는 감정**: 몰입(flow) — "이 사이트 계속 파고들게 되네."
- **다음 행동**: 근거(기사) 펼쳐보기, 또는 계속 관계를 따라가기.

## 10분
- **심리상태**: 탐험이 습관화되기 직전 — 처음으로 "저장해두고 싶다"는 생각이 든다.
- **무엇을 보는가**: 5개 이상 대상/근거를 오간 상태. 원래 보러 온 것과 무관해 보이는 주제까지 도달(예: 아이폰17 → TSMC → 반도체 시장 → 미중 관세).
- **왜 클릭하는가**: 이제는 "원래 뭘 보러 왔는지"를 잊고 순수 호기심으로 클릭.
- **왜 머무는가**: "여기까지 왔는데 이건 또 뭐지" — 호기심 관성.
- **KPI**: 10분 시점 세션 생존율, 공유 버튼 클릭률(이 시점에 처음 공유 충동이 발생).
- **느껴야 하는 감정**: 놀라움("이게 이렇게 연결돼 있었어?") + 정보 우월감의 씨앗.
- **다음 행동**: 공유하기, 계속 탐험, 또는 피로 임계점 도달로 이탈.

## 하루 뒤
- **심리상태**: 어제 본 것 중 하나가 잔상으로 남음 — "그거 어떻게 됐지?"
- **무엇을 보는가**: 재방문 시 "오늘 새로 바뀐 것" 피드. 어제 본 대상의 변화가 있으면 최우선 노출.
- **왜 다시 오는가**: 어제 탐험한 대상의 다음 이야기가 궁금해서, 또는 습관적으로.
- **KPI**: D+1 재방문율.
- **느껴야 하는 감정**: "역시 뭔가 바뀌어 있네" — 신뢰와 습관의 시작.
- **다음 행동**: 어제 대상 재확인, 또는 새 탐험 시작.

## 일주일 뒤
- **심리상태**: "뉴스 앱"에서 "이슈 추적 도구"로 멘탈 모델 전환 완료.
- **무엇을 보는가**: 익숙해진 골격, 처음 봤던 대상의 "역사"가 눈에 띄게 두꺼워진 것을 체감.
- **왜 다시 오는가**: 특정 대상의 결말/다음 단계가 궁금해서 — "팔로우/저장" 욕구가 뚜렷한 기능 요구로 발전.
- **KPI**: W1 재방문율, 세션당 평균 탐험 깊이의 안정화 여부.
- **느껴야 하는 감정**: 소속감 — "이건 내가 챙겨보는 사이트."
- **다음 행동**: 브라우저 북마크, 지인 추천, 사이트명+키워드 검색 재진입.

## 한 달 뒤
- **심리상태**: 습관화 완료 또는 이탈 완료 — 진짜 승부처.
- **무엇을 보는가(습관화 성공 케이스)**: 매일/매주 정기 확인 루틴, "세상이 지금 어떻게 돌아가는지" 확인하는 대시보드로 자리잡음.
- **왜 다시 오는가**: 이 사이트만의 방식이 있다는 확신.
- **KPI**: M1 리텐션, 세션당 탐험 깊이가 최초 방문 대비 유지/증가하는지(콘텐츠가 두꺼워지는 걸 체감하는지의 대리지표).
- **느껴야 하는 감정**: 확신 — 브랜드로서의 인식.
- **다음 행동**: 이 시점부터 팔로우/알림(Phase 3) 수요가 실질적으로 발생 — Product Bible 로드맵과 정합.

# Part B. 진입 경로별 설계

## 1. 검색 유입 (Google/Naver)
- **의도**: 특정 키워드(예: "아이폰17 카메라")의 답을 이미 찾는 중 — 질문형.
- **첫 화면**: Topic/Entity 페이지 직행(홈을 거치지 않음). "지금" 섹션이 검색 의도에 즉답해야 이탈하지 않는다 — SEO 스니펫과 실제 내용의 정합성이 핵심.
- **리스크**: "총정리"류 키워드로 왔는데 내용이 빈약하면 즉시 이탈, 신뢰 손상.
- **기회**: 질문에 답한 직후 "역사"/"연결" 섹션으로 자연 유도 — 검색 의도는 충족했지만 "어, 이것도 있네" 하는 보너스 발견.
- **이 경로의 KPI**: 스니펫 클릭 후 3초 이탈률, 검색 유입 세션의 평균 탐험 깊이(다른 채널보다 낮을 수 있음 — 목표는 이 채널도 2페이지 이상으로 끌어올리는 것).

## 2. AI 검색(ChatGPT/Perplexity 등) 유입
- **의도**: AI가 이미 요약해준 답의 "원문/근거 확인" 목적 — 구체적이고 신뢰 검증 목적.
- **첫 화면**: 인용된 Node summary 또는 원문 기사와 정확히 일치하는 내용이 상단에 있어야 한다 — "AI가 말한 게 맞네" 확인 즉시 이탈할 위험이 가장 큰 채널.
- **기회**: 이미 이 주제에 관심 있는 것으로 검증된 방문자 — 확인 직후 배치된 첫 관계 카드의 explanation 품질에 잔류 여부가 달려 있다.
- **설계 원칙**: "AI 검색으로 오셨다면" 식의 노골적 유도는 하지 않는다(부자연스러움). 대신 summary 직후 배치되는 첫 관계 카드가 이 채널의 유일한 생존 지점 — Product Bible 5장 "인용용 문장 vs 탐험 유도용 문장 분리" 원칙이 가장 첨예하게 작동한다.
- **KPI**: 리퍼러 특정이 어려운 채널 — UTM/리퍼러 패턴 분석은 Phase 2 과제로 별도 기록.

## 3. SNS 공유 유입 (Threads/X)
- **의도**: 타임라인의 훅 카피에 이끌려 옴 — 감정적, 충동적 클릭.
- **첫 화면**: Story 페이지(현재 Threads는 Story 링크 공유, Product Bible 로드맵상 Phase 2에 Node 중심 전환 예정) — 공유 카피가 약속한 것(침묵지수, 놀라움)을 즉시 확인시켜야 한다.
- **왜 체류하는가**: 공유 카피의 약속이 지켜졌다는 확인 + "이 근거가 속한 대상" 배너로 즉시 확장 기회 제공.
- **리스크**: 공유 카피와 실제 내용의 괴리(낚시성) — Product Bible 0장 원칙 위반 시 신뢰가 즉시 붕괴되고 재방문이 없다.
- **기회**: 감정적으로 이미 활성화된 상태라 다음 클릭 저항이 가장 낮은 채널 — 배너 하나로 대상 페이지에 진입시키면 탐험 모드 전환 확률이 높다.
- **KPI**: Story→대상 배너 클릭률(이 채널 전용 핵심 지표), 세션 내 재공유율.

## 4. 기사 링크 유입 (타 매체의 인용/링크)
- **의도**: 제3자 신뢰 보증을 거쳐 옴 — 검색보다 이미 신뢰도가 높은 상태로 시작.
- **첫 화면**: 링크가 가리키는 특정 Story 또는 대상 페이지.
- **기회**: "이 사이트가 인용될 정도면 믿을 만하다"는 사전 신뢰 — 탐험 전환이 가장 쉬운 채널일 가능성.
- **KPI**: 이 채널의 세션당 탐험 깊이(전 채널 중 최고치로 기대 — 다른 채널 설계의 검증 기준으로도 활용).

## 5. 메인페이지 직유입 (즐겨찾기/직접 타이핑/습관적 방문)
- **의도**: 막연한 탐험 — "오늘 뭐 있나 보자." 목적지 없는 방문.
- **첫 화면**: 홈 "지금 움직이는 것" + "오늘 새로 바뀐 것" — 검색 의도가 없으므로 흥미 유발이 전부.
- **기회**: 이미 재방문자일 확률이 높은 채널 — "매번 다른 조합" 원칙(Product Bible 2장)이 가장 중요하게 작동.
- **KPI**: 홈 진입 후 첫 클릭까지 걸리는 시간, 홈에서의 스크롤 깊이.

## 6. Topic 페이지 직유입 (북마크한 특정 대상 재방문)
- **의도**: 특정 대상의 "그동안 뭐가 바뀌었는지" 확인 — 가장 목적이 뚜렷한 재방문.
- **첫 화면**: 그 대상 페이지, "오늘"/"역사" 섹션에서 지난 방문 이후 추가된 것이 명확히 구분되어야 한다(Phase 1엔 "마지막 방문 이후" 개인화가 없으므로 최신 update의 타임스탬프를 눈에 띄게 배치).
- **기회**: 사실상 "팔로우"의 원형 행동 — Phase 3 팔로우 기능의 최우선 타겟 세그먼트.
- **KPI**: 이 세그먼트의 D+7/D+30 재방문율(Product Bible 노스스타의 핵심 검증 대상).

# 종합

세 문서의 역할 분담이 이걸로 완성된다:

- **Product Bible** — 왜 이런 제품이어야 하는가(철학, 원리, 결정사항).
- **User Journey**(이 문서) — 그 철학이 실제 사람의 30초·3분·하루·한 달 안에서 어떻게 느껴지는가, 어떤 문에서 들어온 사람이 어떤 심리로 움직이는가.
- **Implementation Bible** — 그것을 실제로 어떤 파일·순서·DB로 만드는가.

세 문서를 함께 검토한 뒤 Step 0으로 진입한다.
